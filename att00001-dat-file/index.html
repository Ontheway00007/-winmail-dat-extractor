ATT00001.dat and other strangely named attachments

Not every TNEF container arrives called winmail.dat. Depending on the mail server and client, the same file can appear as ATT00001.dat, ATT00002.txt, win.dat, winmail.dat.bin or simply “Part 1.2”. The handling is identical.

By the Winmail.dat Extractor team·4 min read

The names you are likely to see

FilenameUsual explanation
winmail.datThe standard name Outlook gives a TNEF container
win.datA shortened variant produced by some gateways and older clients
ATT00001.dat, ATT00002.datA placeholder assigned when the MIME part has no filename; the number increments per part
ATT00001.htm, ATT00001.txtUsually the alternative body of the message rather than a real attachment
Part 1.2, Mail Attachment, nonameGeneric labels used by iOS Mail, some webmail and mailing-list software
winmail.dat.binAn extra extension added by a download or transfer step

The name is cosmetic. What matters is the content, and the only reliable test is to check the file signature — which is exactly what an extractor does before attempting anything.

Why the name changes in transit

An email attachment carries its filename in MIME headers. When the sending client omits the name, or a gateway strips or rewrites headers during virus scanning, signature stamping or list distribution, the receiving client has to invent something. Apple Mail uses part numbers, other clients use ATT-prefixed placeholders, and some archiving systems add a .bin suffix.

The ATT00001.htm and ATT00001.txt variants are slightly different: those are usually the HTML or plain-text alternative body that a gateway exposed as a file. They contain the message text you already read, so they can normally be discarded.

How to open them

Save the attachment under whatever name it has and select it in the extractor. The tool verifies the TNEF signature rather than trusting the extension, so a container named Part 1.2 or ATT00001.dat is handled exactly like winmail.dat.

If the signature check fails, you have a genuinely different file. Common non-TNEF .dat files include database exports, game save data, application caches and Microsoft Access data — those need the program that produced them, and the sender is the fastest way to find out which.

When you receive several numbered attachments

Messages that pass through gateways sometimes arrive with a handful of parts: ATT00001.htm, ATT00002.dat, ATT00003.png. A practical order of work:

  1. Try the .dat parts in the extractor first — that is where real documents usually hide.
  2. Open the .htm or .txt parts in a browser or text editor if the message body looked incomplete.
  3. Treat small .png, .gif or .jpg parts as signature graphics unless you were expecting images.
  4. If nothing useful appears, reply and ask for a resend in HTML format.

Frequently asked questions

Is ATT00001.dat the same as winmail.dat?

Usually yes. It is typically the same Outlook TNEF container with a placeholder name assigned because the filename header was missing.

What is ATT00001.htm?

It is normally the HTML version of the message body exposed as a file by a mail gateway, not a separate document.

Why do I get Part 1.2 instead of a filename?

Apple Mail labels unnamed MIME parts by their position in the message, so Part 1.2 is a location rather than a real filename.

Can I delete the ATT files?

Once you have extracted anything useful, yes. Alternative-body parts and signature images can be discarded safely.

What if the .dat file is not TNEF?

Then it belongs to another application. Ask the sender which program created it, because a .dat extension carries no format information.
