How to open winmail.dat on Windows 11 and 10

Windows has no built-in handler for TNEF, so double-clicking winmail.dat opens the “How do you want to open this file?” dialog and nothing useful happens. Here are the three routes that do work, starting with the one that needs no software at all.

By the Winmail.dat Extractor team·6 min read

Quick answer
  • Do not rename the file — TNEF is a package, so a .pdf or .docx extension only produces a corrupt document.
  • Fastest route: save the attachment, then extract it in Edge or Chrome with a client-side extractor.
  • If you have Outlook, opening the original message in Outlook usually resolves the container automatically.
  • Never let Windows “always open” .dat files with an application chosen at random.

Method 1: extract it in your browser (no install)

This is the fastest and safest option on a managed work laptop, because it requires no administrator rights and no download of an unknown executable. Save the attachment, open the extractor, and drag the file onto the drop area. Drag and drop works from File Explorer, from the desktop and from the Edge downloads flyout.

The parsing runs in JavaScript on your PC, so confidential contracts and payroll files are never uploaded. When the list of recovered files appears, download the ZIP and unpack it with the built-in Windows extractor: right-click the archive, choose Extract All, then confirm the destination folder.

Corporate PCs: because there is no installer and no upload, this method usually satisfies IT policies that block third-party converters. Check the source code first if your security team requires it.

Method 2: let Outlook do it

If Outlook is installed and the message is in an account Outlook can access, open the original email there. Outlook recognises TNEF and rebuilds the message, showing the attachments as normal files that you can save with File › Save Attachments.

If the message arrived in a different mailbox, forward it to an address that Outlook opens, or ask a colleague with Outlook to forward the extracted files back. Outlook on the web with a Microsoft 365 mailbox behaves the same way.

Note that dragging winmail.dat into an open Outlook window does not work: Outlook resolves TNEF as part of receiving a message, not as a file it can open directly.

Method 3: command line and batch recovery

For repeated or scripted recovery, a command-line TNEF unpacker is convenient. On Windows the practical options are the tnef utility inside Windows Subsystem for Linux, or a PowerShell script that calls a TNEF library. In WSL, installing the distribution’s tnef package and running it against the container writes the attachments into the current directory.

This route suits a helpdesk that receives many affected messages, or an archive migration where hundreds of stored containers need unpacking. For a single file, the browser method is quicker.

What not to do

  • Do not rename the file. Changing winmail.dat to report.pdf cannot work; the bytes are a container, not a PDF.
  • Do not set a default app for .dat. The extension is used by unrelated programs, so a permanent association causes confusion later.
  • Do not install a random “DAT opener” from a search ad. This category attracts bundled adware. Prefer a client-side tool or a well-known open-source utility.
  • Do not upload sensitive attachments to unknown converters. A server-side converter necessarily receives a copy of the document.

Frequently asked questions

Can Windows 11 open winmail.dat natively?

No. Windows has no TNEF handler, so the container has to be parsed by Outlook or an extractor before its contents become normal files.

How do I open winmail.dat without Outlook?

Use a client-side extractor in Edge or Chrome. Save the attachment, select it in the extractor and download the recovered files as a ZIP.

Is there a Microsoft tool for winmail.dat?

Microsoft ships TNEF support inside Outlook and Exchange rather than as a standalone utility, so there is no official separate unpacker to download.

Why is winmail.dat 0 KB?

A zero-byte container means the download failed or the mail gateway stripped the content. Ask the sender to resend before trying to extract it.

Does Windows Mail open winmail.dat?

No. The Mail and Outlook for Windows apps built on the new engine do not reliably decode TNEF from external senders, so the same extraction steps apply.

Can I extract several winmail.dat files at once?

The browser extractor handles one container at a time. For batches, a command-line TNEF utility in WSL is a better fit.
